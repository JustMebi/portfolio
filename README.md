# Developer Portfolio

This repository contains the source code for my personal developer portfolio.

The portfolio showcases selected web and mobile applications, with a focus on production-grade systems, real-world problem solving, and clear engineering decisions rather than visual design.

---

## What This Portfolio Demonstrates

- Building scalable web and mobile applications
- Translating product requirements into working software
- Clean project structure and maintainable code
- State management, API integration, and error handling
- Working on real-world, evolving codebases
- Clear communication of technical decisions

---

## Featured Work

The portfolio includes case studies and demos for:

- Production-grade React Native applications (client work)
- Multi-role web systems (admin, user, and security workflows)
- Personal product experiments, including AI-powered tools
- In-progress systems documented with architecture and trade-offs

Some projects are client-owned and cannot have source code publicly shared. In such cases, demo videos and architectural explanations are provided instead.
